# Testing Bot - Telegram Бот для Тестирования

Полнофункциональная система управления тестами с поддержкой разных ролей: администраторы, учителя и студенты.

## Основные возможности

### 👨‍💼 Администраторы
- ✅ Создание дисциплин
- ✅ Управление пользователями
- ✅ Назначение учителей (по Telegram ID)
- ✅ Назначение администраторов (по Telegram ID)
- ✅ Динамическое сохранение новых администраторов в файл

### 👨‍🏫 Учителя
- ✅ Создание тестов для дисциплин
- ✅ Добавление вопросов к тестам (с вариантами A, B, C, D)
- ✅ Установка баллов за каждый вопрос
- ✅ Просмотр результатов студентов
- ✅ Просмотр рейтингов по тестам

### 👨‍🎓 Студенты
- ✅ Прохождение тестов по дисциплинам
- ✅ Получение оценок за правильные ответы
- ✅ Просмотр своих результатов
- ✅ Просмотр рейтингов студентов

## Система ролей

- **Администраторы** определяются в `config.py` через `ADMIN_IDS`
- При запуске бот автоматически загружает администраторов из `config.py` и `admins.json`
- Администраторы могут назначать новых администраторов, которые сохраняются в `admins.json`
- Администраторы могут назначать учителей
- Все остальные пользователи автоматически регистрируются как студенты

## Команды

### Для всех пользователей

| Команда | Описание |
|---------|---------|
| `/start` | Начать регистрацию |
| `/help` | Справка по командам (актуальны для вашей роли) |
| `/commands` | Полный список всех команд |

### Для администраторов

| Команда | Описание |
|---------|---------|
| `/admin` | Открыть администраторское меню |
| `/student` | Пройти тест (если нужно) |

**Функции администратора:**
- 📚 **Дисциплины** - создание и управление дисциплинами
- 👥 **Пользователи** - просмотр всех пользователей
- ➕ **Добавить учителя** - назначить учителя по Telegram ID
- 👨‍💼 **Добавить админа** - назначить администратора по Telegram ID

### Для учителей

| Команда | Описание |
|---------|---------|
| `/teacher` | Открыть меню учителя |
| `/student` | Пройти тест (если нужно) |

**Функции учителя:**
- 📝 **Мои тесты** - просмотр созданных тестов
- ➕ **Создать тест** - создание нового теста с вопросами
- 📊 **Результаты** - просмотр результатов студентов по вашим тестам

### Для студентов

| Команда | Описание |
|---------|---------|
| `/student` | Начать проход тестов |

**Функции студента:**
- 📚 **Выбор дисциплины** - выберите предмет
- 📝 **Выбор теста** - выберите тест по предмету
- ✏️ **Прохождение теста** - ответьте на все вопросы
- 📊 **Мои результаты** - просмотр своих оценок
- 🏆 **Рейтинги** - просмотр рейтингов студентов

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/denys767/UntitledN-testing_bot.git
cd UntitledN-testing_bot
```

### 2. Установка зависимостей

```bash
pip install aiogram
```

### 3. Конфигурация

Отредактируйте файл `config.py`:

```python
TOKEN = "ВАШ_TELEGRAM_BOT_TOKEN"
ADMIN_IDS = [id, id2, id3]  # Ваш Telegram ID для начального администратора
ADMINS_DB = "admins.json"
```

## Запуск

```bash
python bot.py
```

После успешного запуска отправьте `/start` боту в Telegram.

## Использование

### Пример 1: Регистрация администратора

```
1. Добавьте свой ID в config.py в список ADMIN_IDS
2. Отправьте /start боту
3. Введите имя и фамилию
4. Выберите год выпуска и специальность
5. ✅ Вы зарегистрированы как администратор
```

### Пример 2: Администратор добавляет учителя

```
1. /admin
2. Нажимаем "➕ Добавить учителя"
3. Вводим Telegram ID учителя
4. ✅ Пользователь назначен учителем
```

### Пример 3: Администратор добавляет администратора

```
1. /admin
2. Нажимаем "👨‍💼 Добавить админа"
3. Вводим Telegram ID нового администратора
4. ✅ Пользователь назначен администратором
5. Администратор сохраняется в admins.json
```

### Пример 4: Учитель создает тест

```
1. /teacher
2. Нажимаем "➕ Создать тест"
3. Выбираем дисциплину
4. Вводим название и описание теста
5. Устанавливаем максимальный балл
6. Добавляем вопросы с вариантами ответов
7. ✅ Тест создан
```

### Пример 5: Студент проходит тест

```
1. /student
2. Выбираем дисциплину
3. Выбираем тест
4. Отвечаем на все вопросы
5. Получаем результат и рейтинг
6. Можем просмотреть результаты и рейтинги
```

## Управление администраторами

Администраторы могут быть добавлены двумя способами:

### 1. Через конфигурацию (при запуске)
Добавьте ID в `config.py`:
```python
ADMIN_IDS = [632877422, 623123859, 111111111]
```

### 2. Динамически (во время работы бота)
Администратор может назначить другого администратора через команду `/admin` → "👨‍💼 Добавить админа"

Новые администраторы автоматически сохраняются в файл `admins.json`.

## Структура базы данных

### Таблица `users`
- `user_id` - Telegram ID (PRIMARY KEY)
- `first_name` - Имя
- `last_name` - Фамилия
- `grad_year` - Год выпуска
- `specialty` - Специальность
- `role` - Роль (student/teacher/admin)
- `banned` - Статус блокировки (0/1)

### Таблица `disciplines`
- `id` - ID дисциплины
- `name` - Название дисциплины
- `description` - Описание

### Таблица `tests`
- `id` - ID теста
- `discipline_id` - ID дисциплины (FK)
- `teacher_id` - ID учителя (FK)
- `name` - Название теста
- `description` - Описание
- `max_score` - Максимальный балл

### Таблица `questions`
- `id` - ID вопроса
- `test_id` - ID теста (FK)
- `question_text` - Текст вопроса
- `score_value` - Баллы за вопрос
- `correct_answer` - Правильный ответ (A/B/C/D)

### Таблица `answers`
- `id` - ID варианта
- `question_id` - ID вопроса (FK)
- `answer_text` - Текст ответа
- `answer_key` - Клавиша ответа (A/B/C/D)

### Таблица `student_results`
- `id` - ID результата
- `student_id` - ID студента (FK)
- `test_id` - ID теста (FK)
- `question_id` - ID вопроса (FK)
- `selected_answer` - Выбранный ответ (A/B/C/D)
- `score_earned` - Полученные баллы
